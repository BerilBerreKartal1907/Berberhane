# BERBERHANE - Barber Shop Booking System

Modern ve profesyonel bir berber web sitesi ve randevu sistemi.

## 🚀 Özellikler

- Online randevu alma sistemi
- Hizmet ve fiyat listesi
- Mobil uyumlu tasarım
- Admin panel (randevu yönetimi)
- Çalışma saatleri ayarlama
- Dolu saatleri kapatma
- Google Maps entegrasyonu
- WhatsApp iletişim butonu

## 💡 Amaç

Bu proje, berberlerin müşterilerini daha kolay yönetebilmesi ve  
müşterilerin hızlıca randevu alabilmesi için geliştirilmiştir.

## 🛠️ Teknolojiler

- Web tabanlı uygulama
- Responsive (mobil uyumlu)
- Modern UI/UX tasarım
